# 🎶 Gestor de Canciones Vallenatas

## 📘 Descripción
Este proyecto en **Java** permite **registrar, buscar, listar y eliminar canciones vallenatas** de manera sencilla.  
Se utiliza una **estructura de datos HashMap** para realizar búsquedas rápidas por **nombre, artista o región**.  
El desarrollo y ejecución se realizaron en **Visual Studio Code (VS Code)**.

---

## 🎯 Funcionalidades principales
- Registrar canciones con los datos: **nombre, artista, género y región**.  
- Buscar canciones rápidamente por:
  - Nombre  
  - Artista  
  - Región  
- Listar todas las canciones almacenadas.  
- Eliminar canciones y actualizar la lista.  

---

## 🎵 Canciones utilizadas como ejemplo
| Nombre | Artista | Género | Región |
|---------|----------|---------|--------|
| Amarte más no pude | Diomedes Díaz | Vallenato | Valledupar |
| Las Vainas | Diomedes Díaz | Vallenato | Valledupar |
| Volvamos | Diomedes Díaz | Vallenato | Valledupar |

---

## 🧩 Ejemplo de ejecución
1. Se registran las tres canciones.  
2. Se buscan canciones:
   - Por **nombre** → “Volvamos”  
   - Por **artista** → “Diomedes Díaz”  
   - Por **región** → “Valledupar”  
3. Se listan todas las canciones.  
4. Se elimina **“Las Vainas”** y se lista nuevamente.  
5. Se elimina **“Volvamos”** y se lista otra vez, quedando solo **“Amarte más no pude”**.
